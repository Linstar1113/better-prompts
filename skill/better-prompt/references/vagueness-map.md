# 中文模糊词映射

用户说这些词时，AI 无法直接执行。**不要继续追问"你想要什么样的高大上"**——直接把词拆成可执行特征，写进终版，并在对话里用一行说明你按哪种理解。

面向开发者：表中的"生文/通用"列照常适用，**代码相关与视觉相关的模糊词按下方第三节处理**。

## 一、映射表

| 模糊词 | 可执行特征（选 2-4 条写进终版） |
|---|---|
| 高大上 | 短句为主；少形容词多具体参数；低饱和/极简排版；权威数据或认证背书；完整但不注水 |
| 接地气 | 口语短句；用具体生活场景替代抽象概念；出现"你/咱"；避免书面语与行业黑话 |
| 有感觉 / 有氛围 | 具体画面细节（时间、地点、动作、一个物件）；克制用形容词；一段只写一个画面 |
| 专业一点 | 术语准确；给依据或来源；结构化分点；不下无根据的绝对结论 |
| 年轻化 | 节奏快；网络语点到为止；视觉/句式跳脱；避免说教口吻 |
| 简洁 | 限定字数（如 ≤300 字）；删掉铺垫与重复；一段一个意思；保留具体数字 |
| 高级感 | 信息密度适中；不用感叹号；少用"非常/特别"；名词和动词承担表达 |
| 有温度 | 具体到一件小事；承认对方的处境；给可选动作而不是命令；避免"应该" |
| 走心 | 第一人称叙述；写具体时刻而非总结；允许留白；不喊口号 |
| 大气 | 少细节堆砌；短句；格局/趋势性表述；避免小心思式促销话术 |
| 网感 | 前 3 秒有钩子；短句换行；用平台流行句式；不解释梗 |
| 官方一点 | 第三人称；固定称谓；结论前置；避免口语与情绪词 |
| 有逻辑 | 先结论后理由；标序号；给因果关系；每个论点配证据 |
| 说人话 | 不用术语；一句话不超过 25 字；用具体例子替代定义；避免"赋能/闭环/抓手" |
| 全面一点 | 列维度清单再逐项展开；显式说明哪些维度没覆盖 |
| 更正式 | 去口语词与语气词；完整主谓；书面连接词；统一称谓 |

## 一之二、代码与视觉域的模糊词

生成代码时，"优雅/健壮/高质量"这类词必须落成**可检查的工程约束**；生图时落成**画面与参数**。

| 模糊词 | 落成的可执行约束 | 域 |
|---|---|---|
| 优雅 / 干净 | 单一职责函数 ≤30 行；命名表意不缩写；无嵌套超 3 层；不留注释掉的死代码 | 代码 |
| 健壮 | 列出失败分支与对应行为（返回错误码 / stderr + 非 0 退出）；边界输入（空、超长、非法类型）逐个说明 | 代码 |
| 高性能 | 给可测目标：时间复杂度、单次调用上限、数据量级；说明是否允许缓存 | 代码 |
| 可读性好 / 可维护 | 加类型标注；关键分支加一行注释说明"为什么"；避免魔法数字，抽成常量 | 代码 |
| 现代写法 | 注明语言/框架版本与所用特性（如 async/await、类型注解、组合 API），并说明不兼容的旧写法 | 代码 |
| 重构一下 | 明确"改什么、不改什么"：保持公开签名与行为不变；要拆分的函数或要合并的重复逻辑点名 | 代码 |
| 加个校验 | 校验哪些字段、非法时返回什么（状态码 + 错误体）、在哪一层校验 | 代码 |
| 响应式 | 断点值；每档布局变化（列数、隐藏元素）；最小可用宽度 | 视觉 |
| 简洁 | 代码：单文件、≤N 行、不引入依赖 | 代码 |
| 高级感 / 有质感 | 配色与饱和度；光线方向与软硬；材质描述；留白比例 | 视觉 |
| 现代简约 | 栅格与间距、圆角与阴影、字号层级、主色数量 ≤2 | 视觉 |

## 二、使用规则

1. **一个模糊词 ≤4 条特征**，多了会互相稀释、变成空话。
2. 只在**与交付物直接相关**时才展开。例如用户说"产品图要高级感"，就映射成视觉特征；说"文案要高级感"，就映射成用词特征。
3. 展开后在对话里**用一行交代**，例如：`"高大上"我按「短句 + 具体参数 + 低饱和排版」处理；想换另一种理解直接说。`
4. 不确定是哪种理解、且**换理解会让交付物完全不同** → 才值得占一道题的预算（给 2-3 个具体选项，不给"要高冷还是温馨"这种空选项）。
5. **禁止把模糊词原样留在终版提示词里**——那是把问题还给 AI。**同样禁止直接删掉**：用户说出口的要求不能丢，要么映射成可检查的特征，要么改写进【仍不确定】让用户一句话就能补。
6. 禁止用模糊词解释模糊词（"要有质感的高级感"）。每条特征都必须能被检查。

## 三、常见误用

| 误用 | 问题 | 改法 |
|---|---|---|
| "请用高大上的语言" | 等于没改 | 换成"短句为主，每个卖点配一个具体参数" |
| 把所有 10 条特征全塞进去 | 自相矛盾且空泛 | 选 2-4 条最相关的 |
| 用户说 A，你按 B 展开且不说明 | 超出授权 | 明确写出你的理解，让用户一句话就能推翻 |
| 把"年轻化"映射成"多用网络热词" | 容易过时、翻车 | 映射成节奏与句式，而非具体热词 |
